# Pillar 2: Infrastructure, Weight & Supply Chain Security

This pillar focuses on datacenter security, protecting frontier model weights, hardening training pipelines, and securing runtime serving engines from theft or sabotage.

## Submodules in this Pillar

- **07. Weight Exfiltration & Covert Channels**: Smuggling weight shards through subtle API channels. *(Claimed by Ashanti)*
- **08. Egress Monitoring & Rate-Limiting**: Detecting steganographic weight leakage and enforcing bandwidth limits.
- **09. ML Supply Chain & Serialization Exploits**: Pickling attack payloads and migrating to safe safetensors.
- **10. Model Extraction & Distillation Theft**: Black-box teacher cloning attacks and watermarking defenses.
- **11. Inference Engine & KV-Cache Exploits**: Shared prefix caching side channels in multi-tenant inference engines.
